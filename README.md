# Toyota Mark II JZX100 — фан-сайт

Одностраничный сайт о Toyota Mark II в 100 кузове: тёмный JDM-дизайн, большое фото белого седана JZX100, история модели, двигатели, версии, тюнинг и FAQ.

## Файлы

- `index.html` — разметка и весь контент.
- `styles.css` — стили, адаптив, анимации.
- `script.js` — меню, scroll-reveal, табы двигателей, аккордеон.
- `assets/jzx100-hero.jpg` — фотография Mark II для первого экрана.
- `robots.txt` — для публикации на хостинге.

## Как открыть

Просто откройте `index.html` в браузере. Внешние зависимости — только шрифты Google Fonts; без интернета сайт продолжит работать на системных шрифтах.

## Что можно поменять

- Фото в hero — замените `assets/jzx100-hero.jpg` и при необходимости поправьте `object-position` у `.hero-photo-img` в `styles.css`.
- Подпись под фото — блок `.hero-photo-caption` в `index.html`.
- Характеристики двигателей — секция `#specs` в `index.html` (табы и панели).
- Тексты и цифры — прямо в `index.html`, стили — в `styles.css`.
